# 당장만나 — 9명 과제 카드

가이드상 **9명 전원이 AI(Claude Code)로 기능을 1개 이상 구현**해야 합니다. 각자 카드 하나씩 맡아 주세요.
빌드팀(A·B·C)이 먼저 뼈대를 올리면 시작할 수 있어요. 막히면 빌드팀에게 톡 주세요!

## 모든 카드 공통 순서

1. 톡방에 **"지금 ○○ 작업 중"** 한 줄
2. Claude Code에: `GitHub에서 최신 내용 받아와줘.`
3. 아래 카드의 **프롬프트를 그대로 붙여넣기** (처음 한 번은 "CLAUDE.md를 먼저 읽어줘"가 들어 있어요)
4. `index.html`을 더블클릭해서 직접 눌러 보며 **완료 기준** 확인 → 이상하면 "○○가 안 돼. 고쳐줘"
5. Claude Code에: `지금까지 수정한 내용을 main에 올려줘. 커밋 메시지는 [내이름] ○○ 구현 으로 해줘.`
6. **기록 남기기** (PPT P.13): 처음 쓴 프롬프트 → 고친 프롬프트 → 왜 고쳤는지, 결과 화면 캡처

> ⚠️ 내 카드의 파일만 수정해요. 다른 파일을 고쳐야 할 것 같으면 Claude가 고치기 전에 톡방에 먼저 말해 주세요.
