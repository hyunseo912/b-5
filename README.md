# 당장만나

> 모임 날짜·장소·메뉴를 정하느라 카톡이 수십 개 오가는 문제를 **링크 하나**로 해결하는 웹앱
> 삼일회계법인 2026 Discover 신규입사자 연수 사전 미션 · B-5조

## 폴더 구조

```
CLAUDE.md                          Claude Code 공통 규칙 (작업 전 꼭 읽기)
컨텐츠팀전달파일/
  당장만나_모의앱_v4.1.html        디자인 기준 모의 앱 (브라우저로 열어 확인)
  화면별_샘플데이터_명세_v4.1.md    화면별 데이터·계산 규칙 명세
  화면별_샘플데이터_v4.1.json      설정값 + 테스트 참여자 10명 데이터
  테스트_입력데이터_v4.1.xlsx      테스트 입력값 + 집계 정답지
```

지금 루트의 `index.html`은 모의앱 v4.1 임시 복사본입니다. 빌드팀 뼈대가 완성되면 교체됩니다.

## 작업 규칙

- 브랜치를 만들지 않고 `main`에서만 작업합니다.
- 작업 전 톡방에 "지금 ○○ 작업 중" 한 줄 공유 (같은 파일 동시 수정 금지)
- 시작 전 "GitHub에서 최신 내용 받아와줘", 끝나면 "main에 올려줘"
- 커밋 메시지에 이름 + 무엇을 바꿨는지 한 줄
- API 키·비밀번호·실제 개인정보는 절대 올리지 않습니다. (Public 저장소)

※ 샘플 데이터의 이름·숫자·알레르기 정보는 모두 테스트용 가상 데이터입니다.
